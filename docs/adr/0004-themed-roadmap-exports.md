# Theme-specific roadmap exports

Status: accepted

The roadmap keeps one human-authored Excalidraw source and generates light and dark theme variants from it. Both variants use a transparent canvas, explicit GitHub-targeted theme palettes, hue-preserving area fills and borders, and the same issue state, geometry, links, dependencies, and completion styling. The dark area fills are `#164e73`, `#0b5345`, `#4c2a85`, `#6b4f00`, and `#1f6f3d`, corresponding to the existing blue, teal, purple, yellow, and green areas. The neutral foreground is `#212529` in light mode and `#f8f9fa` in dark mode. Secondary neutrals map `#495057` to `#ced4da`, `#868e96` to `#adb5bd`, and `#adb5bd` to `#868e96` in dark mode. Closed nodes use a light neutral gray in light mode and `#343a40` in dark mode, with muted completion marks. A small post-processing step adds a 3 px rounded frame with an approximately 24 px radius and clips the exported corners because Excalidraw does not own the outer image boundary. The renderer publishes `roadmap-light.png`, `roadmap-light.svg`, `roadmap-dark.png`, and `roadmap-dark.svg`, while retaining `roadmap.png` and `roadmap.svg` as exact light-mode compatibility aliases. The README selects the matching PNG with GitHub's `prefers-color-scheme` picture syntax and links the image to the theme-independent authored Excalidraw source. Rendering is atomic: all variants, aliases, and README output must validate before any existing generated file is replaced. CI validates both transparent, framed variants and their README references.
